# Kentucky Basketball Analytics — 2025-26 Season Review

A data-driven analysis of Kentucky's 2025-26 basketball season using KenPom and Synergy Sports data.

## Project Overview
This project examines Kentucky's 2025-26 season through four sections:
- **Section 1** — Team efficiency vs national average (KenPom)
- **Section 2** — Transfer class performance and injury impact
- **Section 3** — Play type efficiency (Synergy Sports)
- **Section 4** — 2026-27 incoming transfer class comparison

## Key Finding
Kentucky's healthy transfer additions were the most efficient offensive group on the roster. Two injuries — Jaland Lowe (shoulder) and Jayden Quaintance (knee) — significantly impacted the season's outcome.
